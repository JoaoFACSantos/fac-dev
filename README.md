# FAC Dev — Portefólio

Portefólio de FAC Developer, com uma animação "scroll cinema" em WebGL: o logótipo vira código, o código vira um site e o site vira um jogo, tudo controlado pelo scroll.

## Estrutura

- `index.html`: página, estilos e animação.
- `dados.js`: conteúdo editável (projetos, stack e links).

## Ver localmente

```bash
python -m http.server 5173
```

Abre `http://localhost:5173`.
